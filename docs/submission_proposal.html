Project Title

SnapGuardian AI — Zero-Cloud Multimodal Privacy, Task Context & NPU Thermal Engine for Snapdragon HP PCs

Executive Summary

Modern PCs suffer from two critical consumer pain points: Data Privacy Risks and Device Overheating & Thermal Throttling. SnapGuardian AI is a zero-cloud desktop suite custom-engineered for Snapdragon-powered HP PCs (Snapdragon X Elite / X Plus). It unifies real-time vision PII masking, local developer task context graphs, zero-cloud speech intelligence, local vector search, and dynamic NPU thermal offloading into one comprehensive solution.

Core Technical Features

  • SnapCooler — Dynamic Thermal Offloader: Delegates background AI workloads to the 45 TOPS Hexagon NPU (1.2W TDP), reducing CPU temperatures by up to 32°C.
  • Real-Time Vision & Text PII Guard: Scans desktop screen frames locally to blur sensitive API keys, credentials, and tokens.
  • Task Context Graph & Proactive Debugger: On-device graph builder mapping projects, files, errors, and dependencies with 0 cloud network calls.
  • Zero-Cloud Voice Intelligence: Offline Whisper STT model running on Hexagon NPU (22x faster than real-time speed).
  • Local Vector Knowledge Base: MiniLM ONNX vector store for instant offline document search.
  • Live NPU Benchmarker: Interactive profiler measuring real-time latency (1.8ms vs 14.5ms CPU) and power consumption.
